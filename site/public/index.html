Vyshyvanka

A DiceBear avatar style of Ukrainian counted-thread embroidery: one quarter mirrored into four, in a border, stitched in a regional palette. A seed draws the same avatar everywhere.

GitHub npm

Use

pnpm add @lbklauncher/dicebear-vyshyvanka
import { vyshyvankaDataUri, vyshyvankaSvg } from '@lbklauncher/dicebear-vyshyvanka';

img.src = vyshyvankaDataUri(seed); // in the browser
const svg = vyshyvankaSvg(seed); // on the server
